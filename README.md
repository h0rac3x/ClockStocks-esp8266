# ClockStocks-esp8266

This is a clock made with an ESP8266 and a 16x2 lcd Display, that shows stocks price variation and value.
It use the finnhub.io API to work.

To use it you need to get the api, put it in the code and put the wifi credential to connect the esp to the world.
There are comments to explain where add the api and how add stocks (defaullt stocks are TSLA, AAPL, MSFT and META).
